# Change Log

## Unreleased

- The sidebar Walk section edits the file types, include globs, and exclude globs used when counting a workspace or directory, and toggles `.gitignore`, `files.exclude`, and unrecognized files.

## 1.0.0

- Count code, comment, and blank lines in the workspace, a folder, or the active editor.
- The activity bar lists those commands. Real-time Counter shows whether the status bar count is on.
- A count opens in an unsaved Markdown preview and is discarded when that preview closes.
- The workspace or directory row shows a spinning icon while that count is running.
- Maintained by che-11, based on vscode-counter by Kentaro Ushiyama.
